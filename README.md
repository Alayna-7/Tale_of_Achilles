Tale Of Achilles

A small text based game based on the myth of Achilles' and the inevitability of fate as it apeares in Greek Mythology.

# Installation
Download the Tale_Of_Achilles.exe file and run the game from where the .exe file is downloaded.

# Usage
To progress the story press 'ENTER'. To make choices, player will be given the options '1' or '2', type whichever choice user wishes and press ENTER to proceed.
